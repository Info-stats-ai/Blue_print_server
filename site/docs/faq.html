FAQ

Do I-IDE have to use a team session?

No. In solo mode, I-IDE is a normal editor with an AI beside you, and nothing is shared with a team.

Can I-IDE use my own API key?

Yes. My AI and the Agent Panel use your own key. See Set up your AI.

Can two agents work in one file?

Yes, as long as they stay in different functions. See Function claims.

Does I-IDE replace Git?

No. Sessions share live work, and you still commit and push with Git.

Is my code stored on your server?

Code you sync in a session is. See Security and data.

Can I-IDE work with VS Code or Cursor shortcuts?

Yes. Choose them as your Base Keymap on the welcome page or in settings.

How do I-IDE get I-IDE?

I-IDE is in private development. Join the waitlist for access.
