Triage

Triage reviews the session's synced files and recent chat, and reports what needs your attention.

Run triage

  1. If you own the session, select the list button in the tool row. You can also type @agent triage in team chat.
  2. The chat says Requesting triage…, then shows the report.

If nothing has been synced yet, the chat says there's nothing to triage.

Important

Triage sends synced files and chat to the AI provider using the shared key. AI limits apply.
