Finding and navigating

Use these tools to move around a project without taking your hands off the keyboard.

Open a file

  1. Press Cmd+P.
  2. Type part of the file name.
  3. Press Return to open the highlighted result.

Search

PressTo search
Cmd+FThe current file.
Cmd+Shift+FThe whole project.
Cmd+Shift+OSymbols in the current file.
Cmd+TSymbols across the project.

Move around

PressTo
Ctrl+GGo to a line number.
Ctrl+Shift+TabSwitch between open tabs.
Cmd+Shift+EFocus the Project Panel.
Cmd+Shift+BFocus the Outline Panel.
Alt+Cmd+OOpen a recent project.
