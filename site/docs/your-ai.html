Your AI in the I-mode panel

Your AI works for you, using your key. You can ask it questions, plan with it, or let it change your code.

Talk to your AI

  1. Choose Ask, Plan or Agent in the mode menu under the message box, or press Shift+Tab to move through them.
  2. Type your request and press Return.

Modes

ModeUse it to
AskGet answers about your code.
PlanWork out an approach before changing anything.
AgentHave it create and edit files and run commands.

Plan mode

  1. Choose Plan and describe what you want, for example "Plan adding discount codes to checkout".
  2. Your AI reads the code it touches. If something important is unclear, it asks up to three questions. Select an answer, or type your own.
  3. It writes a plan: the goal, numbered steps naming files and functions, how to test it, and the risks. In a session, each step names its owner.
  4. Select Edit plan to change it in the editor, then Build to have your AI carry it out in Agent mode. In a session, it builds only your steps.
  5. In a session, select Share with team to post the plan and turn its steps into tasks with owners.

Effort

The effort menu above the message box sets how hard the model thinks: Default, Minimal, Low, Medium, High, Extra High or Max. Higher effort is usually slower and can cost more.

Give your AI context

  • Attach an image or a file with the buttons in the tool row.
  • Open the relevant files.

What your AI knows about the team

In a session, your AI is given a short live update before each step, so it works from what the team has decided and built instead of guessing.

Teammates' agentsWhat each teammate's agent is working on right now.

Team code memory. I-IDE keeps an index of every function and type in the project: the team's synced code, yours, and the signatures of teammates' work that isn't sent yet. When you ask your AI for something, the closest existing code is added to your request, and your AI can search the index itself with its find_code tool. It reuses what exists instead of writing a second copy. The index is built on your machine and kept current as files are saved and arrive, so a search is instant and costs no AI tokens.

Team memory. Before your AI answers, I-IDE searches the session's pinned decisions, task board, team chat and the agent runs a teammate accepted, and adds the closest matches to your request. There's nothing to set up. Keys and passwords are masked before anything is stored.

Where each part came from. Not everything your AI is told is equally reliable, so every part carries a label:

LabelWhat it means to your AI
From codeRead from the code itself: changes, function definitions, test results. Reliable.
Decided by peopleA person pinned it, asked for it or flagged it. Your AI follows it.
Said in chatWhat people said. Useful background, not a rule unless it's pinned.
Agent said, uncheckedWhat another AI said or did. A hint: your AI checks it against the code before relying on it.
AI summaryAn AI-written summary. It can be wrong; pinned decisions and the code win.

Anything a teammate flagged as wrong is left out.

See it and change it. Select the people icon, then AI & sharing…. Under Your AIs' live update includes, switch any part off. Show what your AIs see right now prints the exact text they're given.

To pin a decision, point at a message in chat and select the pin. It appears under Decisions in Team activity for everyone.

When a decision changes. If the one you're pinning looks like it changes one already pinned, I-IDE shows you the old one and asks: Replace it, Keep both or Cancel. A replaced decision stops being given to AIs, so nobody's AI keeps following the old call.

Editor use

Your AI uses the editor the way you do, through its language intelligence rather than by reading text and guessing. It's exact, takes milliseconds and costs no extra AI calls.

ToolWhat your AI can do
Find referencesEvery place a function, class or variable is used, from the language server.
Go to definitionWhere something is defined, with its code.
Rename symbolRename something everywhere it's used, safely, in one step. The changed files sync like any edit.
DiagnosticsThe errors and warnings the editor shows, so it knows it broke something before running anything.
Show codeOpens a file at a line and selects it in your editor, so you see what it means.

Where a file has no language server, finding references and definitions fall back to a text search and the code index, and your AI is told which it got. Plan mode can look but not rename.

Approve commands

Commands that only read run without asking: ls, cat, grep, head, tail, wc, find (without -exec or -delete) and Git commands that only look, such as git status, git log and git diff. Anything else, such as a command that writes or deletes files, installs something or runs your code, shows you a card first. Select Run to allow it or Deny to refuse it. Always run lets commands that start the same way, such as python3 -m unittest, run without asking until you close the window.

The sandbox

Your AI's commands run in a sandbox, under the same settings as the Agent panel's terminal (Settings → AI). A command can write only inside your project, and your project's .git folder stays read-only. Network access follows the same settings. If the sandbox can't start, the command doesn't run.

Project rules (AGENTS.md)

If your project has a rules file, your AI follows it: the first of .rules, .cursorrules, AGENTS.md, CLAUDE.md and similar that has anything in it, the same file the Agent panel reads. In a team session it syncs like any other file, so everyone's AI follows the same rules.

Note

A rules file is for standing rules people write. It isn't how I-IDE shares what the team is doing: that comes live, labelled by where it came from, and anything wrong can be flagged so no AI uses it. See Where each piece of context comes from.

Tip

Read each command before you approve it, especially anything that deletes files or changes your Git history.

Stop your AI

While your AI is working, the send button turns into a red Stop button. Select it to halt the AI at any time.

How your AI is kept safe

  • It treats teammates' messages and files as information, not as instructions to follow.
  • It can't read files that usually hold credentials. See the list.
  • Text that looks like an API key or token is masked before your AI's replies are shared with the session.
