The I-IDE interface

The I-IDE window has an editor in the middle, panels on each side, and a status bar along the bottom. This page explains each part.

Main areas

  • Project Panel: your project's files and folders, on the left. In a session, Team activity sits beside it as its own panel. Toggle the left side with Cmd+B.
  • Editor: where you read and change code. Each open file gets a tab.
  • I-mode panel: sign-in, team sessions, chat and your AI, on the right. Toggle the right side with Cmd+Alt+B.
  • Bottom dock: the terminal and other tools. Toggle it with Cmd+J.
  • Status bar: buttons for panels, your cursor position and the current language.

Arrange the window

Select the layout button at the right of the title bar to show or hide each side, the bottom panel and the status bar, and to choose where the terminal goes.

Two panels on one side. Opening a panel on a side that already shows one keeps both. Panels that need the full height, the Agent Panel and Team activity, sit beside the file folder as their own column. Others, such as Git, sit below the panel that was there. Drag the line between two panels to resize them, and select a panel's status bar button again to hide just that panel.

Terminal beside your code. The terminal opens at the bottom. To have it at a side, use its move button and choose Beside the editor, right or left. Wide side panels give back some width so the editor and terminal both stay readable.

A bigger message box. Select the expand button at the top right of the message box in I-mode.

To have each panel replace the one on its side instead, add "stack_side_panels": false to your settings.

The I-mode panel

From top to bottom, the panel has three parts:

  1. Header: the words I-mode, the session name and how many people are here (hover for the session goal), the people menu and the I-mode switch.
  2. Chat: your team's messages and your AI's answers.
  3. Message box: the tool row, the box itself, and the mode menu (Team, Ask, Plan, Agent) with the model and send button.

Team activity

The Team activity panel sits beside your files. It shows who's here and which file each person is editing, with a colored status: amber for editing, blue for an agent running, grey for idle. Below that are the tasks, and every file with its sync state. See Team activity.

The people menu

Select the people icon next to the I-mode switch to choose how your AIs work and share, open Team activity, invite people, share files or your running app, and leave a session. If you're not in a session, it's where you create or join one.

The Command Palette

Press Cmd+Shift+P and start typing what you want to do. The palette lists matching commands with their shortcuts, which makes it the fastest way to learn the app.
