Live editing and syncing

When people work on the same file in a session, their edits appear for each other as they type. This page explains how files get shared.

Edit a file together

  1. Open a file while you're in a session. It starts syncing, and it appears under Syncing in the Team tab.
  2. Your teammate opens the same file.
  3. Type as usual. Edits from both of you merge as you go, and you can undo your own changes with Cmd+Z.

People are never blocked from typing. Claims only coordinate agents.

See who is where

Open the Team tab. Collaborators lists who is present, which file each person has open and what their agent is doing.

Sync one file

  • Open the file and select the circle button in the tool row.
  • Or find the file under Syncing in the Team tab and select Sync.

Share files teammates don't have

  1. Select the people icon, then Share files….
  2. Enter a folder, or leave it blank for the whole project.
  3. Select Share.

Files listed in .gitignore are skipped. In a You lead session, only the leader can do this.

Choose how files move

The first time you're in a session, the I-mode panel asks two questions. Nothing moves on its own until you answer.

Send my changes:

ChoiceWhat's sent, and when
On every saveAny project file you or your agents create or change, a moment after it's saved.
When an agent finishesThe files an agent changed, when its run finishes. This covers both your AIs: the Agent Panel and My AI.
When I press SyncNothing, until you select Sync to team.

Teammates' changes:

  • Add automatically: files land in your copy right away. A file you have unsaved edits to is kept as yours.
  • Review first: each file waits in the chat as a card. Select View changes, then Use theirs to take it.

Whichever you choose:

  • Files ignored by Git, your private paths and the protected files below are never sent.
  • Nothing is sent on its own while sharing is paused.
  • A run you stopped, or one that failed, isn't sent with When an agent finishes: its files may be half done. A banner offers Sync to team for those.
  • Deleting a file isn't sent; tell your team instead.

To change your answers, select the people icon, then AI & sharing.

What your AIs learn when a file arrives

When a teammate's file reaches you, both your AIs are told in their next live update: who sent it, what changed, and the functions and classes it defines. If it's still waiting for your review, they're told it isn't in your copy yet. That way they use your teammate's real code instead of guessing at it.

Files that are never synced

To protect your secrets, agents and teammates can't read or write files that usually hold credentials:

  • .env and .env.* files
  • .ssh, .aws and .gnupg folders
  • .npmrc, .pypirc and .netrc
  • Files starting with id_rsa, id_ed25519 or credentials
  • Files ending in .pem, .key, .p12, .pfx or .keystore
Important

This list catches common names, not every secret. A key inside an ordinary source file can still be synced, so keep secrets out of your code.
