Live editing and syncing

When people work on the same file in a session, their edits appear for each other as they type. This page explains how files get shared.

Edit a file together

  1. Open a file while you're in a session. It starts syncing, and it appears under Syncing in the Team tab.
  2. Your teammate opens the same file.
  3. Type as usual. Edits from both of you merge as you go, and you can undo your own changes with Cmd+Z.

People are never blocked from typing. Claims only coordinate agents.

See who is where

Open the Team tab. Collaborators lists who is present, which file each person has open and what their agent is doing.

Sync one file

  • Open the file and select the circle button in the tool row.
  • Or find the file under Syncing in the Team tab and select Sync.

Share files teammates don't have

  1. Select the people icon, then Share files….
  2. Enter a folder, or leave it blank for the whole project.
  3. Select Share.

Files listed in .gitignore are skipped. In a You lead session, only the leader can do this.

Sync your agent's work

When an agent changes files, a banner offers Sync to team. Select it to send those changes to your teammates.

Files that are never synced

To protect your secrets, agents and teammates can't read or write files that usually hold credentials:

  • .env and .env.* files
  • .ssh, .aws and .gnupg folders
  • .npmrc, .pypirc and .netrc
  • Files starting with id_rsa, id_ed25519 or credentials
  • Files ending in .pem, .key, .p12, .pfx or .keystore
Important

This list catches common names, not every secret. A key inside an ordinary source file can still be synced, so keep secrets out of your code.
