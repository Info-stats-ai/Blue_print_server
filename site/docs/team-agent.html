The team agent

The team agent is an optional AI teammate that follows your chat and speaks up when it can help.

Turn it on

  1. If you own the session, select the people icon.
  2. Select Team agent follows the chat. Everyone's chat says it's on.

Select it again to turn it off.

What it does

  • Answers questions it can help with.
  • Points out clashes, such as two people claiming the same work.
  • Writes REFERENCE.md when the team clearly agrees on a plan.

When it stays quiet

It ignores small talk and otherwise stays silent. It waits at least 20 seconds between replies and has an hourly cap.

Example

  1. Bob: "I'll take the tests and the CLI."
  2. Alice: "I'm doing the CLI too." The agent points out the overlap.
  3. Alice: "OK: Bob does tests, I do the CLI. Agreed?"
  4. Bob: "Agreed." The agent confirms the split and writes it to REFERENCE.md.
Important

While it's on, team chat is sent to the AI provider using the service's shared key. AI limits apply.
