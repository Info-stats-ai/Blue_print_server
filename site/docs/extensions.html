Extensions and languages

Add languages, themes and icons from I-IDE's extension store.

Languages that work right away

These need no extension: Rust, Go, Python, TypeScript and JavaScript (including JSX and TSX), C, C++, JSON, YAML, CSS, Bash and Markdown, plus Tailwind CSS and ESLint support.

Install an extension

  1. Open the Command Palette and run extensions, or press Cmd+Shift+X.
  2. Search for a language or theme, such as java or ruby.
  3. Select Install. The extension is ready right away; you don't need to restart.

Installed extensions update on their own. To stop one updating, turn off its automatic updates on the extension's card.

What's in the store

The store has open-source extensions for languages such as Java, Kotlin, Scala, C#, PHP, Ruby, Swift, Dart, Elixir, Haskell, Lua, Zig, HTML, Vue, Svelte, SQL, GraphQL, Terraform and Docker, plus themes and icon sets.

Each one is built by I-IDE from its own published source and keeps its own licence. Extensions without a licence aren't offered.

VS Code extensions

VS Code extensions can't be installed: they're built for a different editor. Many languages they cover are in the store as I-IDE extensions instead.
