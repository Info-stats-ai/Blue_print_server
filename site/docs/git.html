Git

I works with your existing Git repositories. Sessions don't replace Git, so you still commit and push as you normally would.

Open the Git panel

Press Ctrl+Shift+G. The panel lists changed files and lets you stage and commit them.

Commit a change

  1. Open the Git panel.
  2. Select the files to stage.
  3. Enter a commit message.
  4. Commit, then push.

See who changed a line

Press Cmd+Alt+G then B to turn on Git blame for the current file.

Git and team sessions

A session shares live edits between people, which is separate from your commit history. Agree who commits what. A task board with one owner per task makes this easier.
