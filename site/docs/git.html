Git

Git is optional in I-IDE. A session syncs, merges and keeps file versions by itself, so a team can work together without it. If your project is a Git repository, everything here works as usual.

Open the Git panel

Press Ctrl+Shift+G. The panel lists changed files and lets you stage and commit them.

Commit a change

  1. Open the Git panel.
  2. Select the files to stage.
  3. Enter a commit message.
  4. Commit, then push.

See who changed a line

Press Cmd+Alt+G then B to turn on Git blame for the current file.

Git and team sessions

A session keeps its own versions of every synced file, separate from your commit history; see Syncing and merging. If you also commit, agree who commits what. A task board with one owner per task makes this easier.
