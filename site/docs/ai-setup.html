Set up your AI

I-IDE uses AI models from providers you choose, with your own API key. Set this up once, and both the I-mode panel and the Agent Panel can use it.

Add an API key

  1. Get an API key from your provider, such as Anthropic.
  2. Open the Agent Panel with Cmd+?, then open its settings.
  3. Find your provider and paste your key.

Your key is saved on your computer and used to call the provider directly.

Important

Your provider bills you for this usage. Check their pricing before running long agent tasks.

Choose a model

  1. At the bottom of the I-mode panel, select the model name.
  2. Choose a model. The list shows every model your providers offer.

If no model is set up, the panel tells you to pick one or add a provider key.

Use a local model

If you run Ollama on your computer, its models appear in the same list.

Set a default in settings

{
  "agent": {
    "default_model": {
      "provider": "anthropic",
      "model": "claude-sonnet-4-6"
    }
  }
}
