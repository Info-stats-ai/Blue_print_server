Set up your AI

I-IDE uses Claude, with your own API key. You can add an OpenAI key too. Set this up once, and both the I-mode panel and the Agent Panel can use it.

Add an API key

  1. Get a Claude API key from Anthropic (or an OpenAI key).
  2. Open the Agent Panel with Cmd+?, then open its settings.
  3. Under Anthropic (or OpenAI), paste your key.

Your key is saved on your computer and used to call the provider directly.

Important

Your provider bills you for this usage. Check their pricing before running long agent tasks.

Choose a model

  1. At the bottom of the I-mode panel, select the model name.
  2. Choose a model. The list shows the Claude models your key can use, and OpenAI's if you added that key.

With a Claude key, I-IDE picks the strongest Claude model for you until you choose one. Without a key, the model name reads Add a Claude key, and nothing else is picked for you.

Set a default in settings

{
  "agent": {
    "default_model": {
      "provider": "anthropic",
      "model": "claude-sonnet-5-5"
    }
  }
}
