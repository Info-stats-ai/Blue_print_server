Set up your AI

I-IDE uses Claude, with your own API key. No key? Sign in with GitHub Copilot for free. Set this up once, and both the I-mode panel and the Agent Panel can use it.

Free: sign in with GitHub Copilot

  1. Open the Agent Panel with Cmd+?, then open its settings.
  2. Under GitHub Copilot Chat, select Sign in.
  3. Copy the code shown, open the GitHub page, paste the code and approve.

Any GitHub account works. Copilot Free has a monthly limit; a paid Copilot plan raises it.

Add an API key

  1. Get a Claude API key from Anthropic (or an OpenAI key).
  2. Open the Agent Panel with Cmd+?, then open its settings.
  3. Under Anthropic (or OpenAI), paste your key.

Your key is saved on your computer and used to call the provider directly.

Important

Your provider bills you for this usage. Check their pricing before running long agent tasks.

Choose a model

  1. At the bottom of the I-mode panel, select the model name.
  2. Choose a model. The list shows the models your key or Copilot sign-in can use.

Until you choose one, I-IDE picks for you: the strongest Claude model on your own key, or else a Claude model from Copilot. With neither, the model name reads Choose an AI.

Set a default in settings

{
  "agent": {
    "default_model": {
      "provider": "anthropic",
      "model": "claude-sonnet-5-5"
    }
  }
}
