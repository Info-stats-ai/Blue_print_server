Editing code

I-IDE's editor has the tools you'd expect: multiple cursors, code intelligence, formatting and comments.

Multiple cursors

Change several places at once:

PressTo
Cmd+DSelect the next occurrence of the current word.
Cmd+Shift+LSelect every occurrence.
Cmd+Ctrl+NAdd a cursor on the line below.

Code intelligence

I-IDE starts a language server when you open a supported file, and the status bar shows while it downloads. Once it's ready:

PressTo
Ctrl+SpaceShow completions.
F12Go to the definition.
Alt+Shift+F12Find all references.
F2Rename a symbol everywhere.
Cmd+K then Cmd+I-IDEShow details about the symbol under the cursor.
Cmd+.Show code actions and quick fixes.
Cmd+Shift+MList errors and warnings for the project.

Everyday editing

PressTo
Cmd+SSave the file.
Cmd+/Comment or uncomment lines.
Cmd+Shift+I-IDEFormat the file.
Cmd+\Split the editor to the right.
Cmd+WClose the current tab.
