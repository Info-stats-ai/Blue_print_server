Settings reference

These are the settings specific to I-mode. For everything else, open the Settings Editor with Cmd+, and search by name.

collab_mode

Whether I runs on your own or with team features. The I-mode switch changes this for you.

Settingcollab_mode
Default"single"
Options"single" for solo mode, or "multi" for I-mode.
{ "collab_mode": "multi" }

telemetry

Whether I sends usage data and crash reports. Both are off by default.

Settingtelemetry.metrics, telemetry.diagnostics
Defaultfalse

auto_update

Whether I updates itself. It's off because there's no public release channel yet.

Settingauto_update
Defaultfalse
