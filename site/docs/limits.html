AI limits

Limits apply to AI features that use the service's shared key. Your own AI, using your key, isn't affected.

What uses the shared key

  • The team agent
  • Assigning tasks
  • Discussion summaries
  • Triage
  • @agent blueprint

The daily limit

Each session can spend about $2 a day. When it reaches that, shared features pause until the next day (UTC), and the chat says so if you requested one. The amount is estimated from token counts.

What to do when you reach it

  • Choose Ask, Plan or Agent in the mode menu and keep working with your own key.
  • Or wait until the next day.
