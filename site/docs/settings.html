Settings and key bindings

Change settings in the Settings Editor or directly in a JSON file.

Open your settings

PressTo open
Cmd+,The Settings Editor, where you can search for a setting by name.
Cmd+Alt+,Your settings.json file.
Cmd+K then Cmd+SYour key bindings.
Cmd+K then Cmd+TThe theme selector.

Where settings are stored

  • Your settings: ~/.config/i-ide/settings.json
  • Project settings: .zed/settings.json in your project. These override your own settings for that project.

Example

{
  "theme": "One Dark",
  "buffer_font_size": 14,
  "format_on_save": "on"
}
