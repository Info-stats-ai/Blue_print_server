Team activity

The Team activity panel, beside your files, shows what's happening in the session right now: who's here and what each person is editing, the tasks, and what changed.

Open it with its button in the status bar, or from the people menu. It sits below your files; drag the bar between them to share the space.

People

Lists who is present and which file and line each person is on, with a colored label: amber for editing, blue for agent running, grey for idle. Each person keeps one color everywhere. Counts appear only when they're above zero:

CountMeaning
MergesEdits made at the same time that were merged live.
DivergencesChanges that drifted from the shared reference.
Lane warningsEdits outside the person's assigned task.
Agent collisionsTimes an agent stepped back from a function another agent held.
Shared key costEstimated spending on the service's AI key in this session.

Agent runs

Shows the tasks agents in the session took on: the goal, how each one went, what it changed and what the team thought. Teammates can select Accept or Needs changes on a finished run. See Agent runs and sharing.

This week

Shows the conflicts caught across your sessions in the last 7 days. Select Copy summary to get a one-line status you can paste into an update.

Changed this session

Lists files changed during the session. Select a file to open it.

Syncing

Lists the files being shared, with a Sync button for each.

Reference

Shows the shared reference, if your team has one.
