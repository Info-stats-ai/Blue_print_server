Team activity

Team activity is its own panel, next to your file folder. It shows who's here, the tasks, and where every file stands between you and the team.

It opens by itself when you start or join a session. Its button in the status bar shows or hides it, and you can drag the line between it and the file folder to resize it.

People and tasks

People lists who is present and which file and line each person is on. A colored label shows what they're doing: amber for editing, blue for agent running, grey for idle. Tasks come from a plan someone shared; each has an owner and a status. See Tasks.

Sync: Auto or Manual

The switch at the top of Files decides how files move. You can change it at any time.

ModeWhat happens
AutoYour saves go to the team, and teammates' changes arrive on their own and merge with your work. Open files are edited live. Every AI sees changes right away.
ManualNothing leaves your machine until you press the sync button on a file, or Sync all. Teammates' changes wait for you. Their AIs wait for what you haven't sent.

The gear next to the switch holds the finer choices: what teammates see of your AI's work, private paths, and a pause.

Merging and conflicts

When you and a teammate changed different parts of a file, the two versions merge on their own. If you each added a different function, both are kept.

When you both changed the same lines, nothing is merged silently. The file is marked conflict for everyone in the session, with both names, until the person holding both versions picks one or merges them.

Versions, without git

Every version of a file that reaches the team is kept, with who made it and when. Select the clock on a file to list them. View opens the file with what changed since that version marked. Restore puts that version back; it then counts as your newest change.

Git keeps working as usual if your project uses it. See Git.
