Team chat

The I-mode panel is one conversation: header, chat, message box. The mode menu under the message box decides who reads what you send.

Choose who gets your message

Select the mode menu at the bottom left of the panel, or press Shift+Tab in the message box to move through the modes.

ModeWho reads it
TeamThe people in the session. No AI.
AskYour AI, which answers questions and changes nothing.
PlanYour AI, which reads the code, asks what it needs, then writes a plan. See Plan mode.
AgentYour AI, which writes code and runs commands.

A session starts on Team. When the team has agreed what to do, end a message with @agent to hand the agreed work to your AI; the mode switches to your AI for the messages that follow.

What stays in the chat

Messages, your AI's answers and files teammates send stay in the chat. Short notices, such as someone joining or a setting you changed, show for a few seconds above the message box and then go away.

Choose how files move

How files move between you and the team is set in Team activity, with the Auto / Manual switch. See Team activity.

A bigger message box

The message box grows as you type, up to eight lines. For a long message, select the expand button at its top right; select it again, or send, to make it small again.

The tool row

These buttons sit above the message box. Hover over any of them to see its name.

ControlWhat it does
+ menuAdd an image, send the open file to the team, write the team plan, or run triage (owner only).
Paper clipAttach a file.
MicrophoneStarts macOS dictation.
FilesHow files move in this session.
ThinkingHow hard your AI thinks. Shown only when you're talking to your AI. See Effort.

See the team at a glance

Who's here and which file each person is editing, the tasks and the latest changes are in the Team activity panel beside your files. Open it with its button in the status bar, or from the people menu.
