The Agent Panel

The Agent Panel gives you longer-running AI threads, separate from the I panel. Press Cmd+? to open it.

When to use which

UseFor
I panelQuick requests alongside team chat.
Agent PanelBigger tasks, separate threads, and tasks started from the task board.

Use it with your team

Agent Panel threads are private to you, and they still work with your team:

  • An agent can check what your team is doing when your request needs it, using its team_context tool.
  • It follows the same function claims as other agents.
  • Its edits appear in the I panel, where you can select Sync to team.

Other agents

The welcome page and Agent Panel let you install other agents, such as Claude Agent, Codex, GitHub Copilot and Cursor. Each uses its own account or key.

Control what agents can do

Use tool_permissions in your settings to allow, block or always confirm actions:

{
  "agent": {
    "tool_permissions": {
      "tools": {
        "terminal": {
          "default": "confirm",
          "always_allow": [{ "pattern": "^pytest" }]
        }
      }
    }
  }
}

Connect outside tools

Add Model Context Protocol (MCP) servers to give agents more tools:

{
  "context_servers": {
    "my-server": {
      "command": "some-command",
      "args": []
    }
  }
}
