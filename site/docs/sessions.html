Sessions

A session is where your team's work comes together. This page covers creating, rejoining and leaving one.

Create a session

  1. Select the people icon next to the I-mode switch.
  2. Select New session….
  3. Enter a name and a goal. Both are optional, but a clear goal helps people and agents.
  4. Choose how the session is run:
    • You lead: you control file sharing and assign tasks.
    • No leader: everyone has equal access.
  5. Create it. You become the owner.

Leader and no-leader sessions

ActionYou leadNo leader

Come back to a session

I-IDE remembers your last session and rejoins it the next time you open the app. If your connection drops, I-IDE reconnects by itself and the chat says so. If it can't reconnect, join again from the people menu.

Leave a session

Select the people icon, then Leave session. You stay a member, so you can come back later.
