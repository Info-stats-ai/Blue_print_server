Controls and commands

A quick reference for the I-mode panel and team chat.

People menu

ItemWhat it doesWho sees it
Sign inOpens the sign-in page.Signed out
New session…Creates a session you own.Not in a session
Join session…Asks to join using an invite link.Not in a session
Invite by email…Emails someone an invite.In a session
Share files…Sends files teammates don't have.In a session
Share running app…Shares an app on your localhost.In a session
Team agent follows the chatTurns the team agent on or off.Owner
Link GitHub repo…Links a repository for pull request comments, once the I-IDE GitHub App is installed on it. This isn't available yet.Owner
Copy invite linkCopies the link people use to ask to join.In a session
Leave sessionDisconnects you. You stay a member.In a session
Log outSigns you out.Signed in

Chat commands

TypeWhat happens
Start with @aiAsks your own AI.
End with @agentHands the request to your own AI, which can change files.
@agent blueprintWrites or replaces the shared reference with the shared key. Owner only.
@agent triageRuns triage. Owner only.
