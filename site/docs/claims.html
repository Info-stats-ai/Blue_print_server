Function claims

Function claims stop two agents from changing the same code at once, while letting them share a file.

How claims work

  1. Before an agent writes to a file, it claims the functions it will change.
  2. I checks those functions against every other agent's claims, including your other agents and your teammates'.
  3. If nothing clashes, the agent goes ahead.
  4. If another agent holds one of those functions, the agent steps back and the chat shows a message, such as "Collision avoided: Bob's agent stepped back from TaskStore.complete; Alice's agent is already changing it."

An agent that can't say in advance where it will edit claims the whole file, which clashes with any other claim on that file.

What claims don't do

  • They don't block people. You can always type in any file.
  • They don't lock your Git branch. They only coordinate live agent work.

Why not lock files?

A file lock lets only one agent work in a file at a time, so a team is capped at one agent per file. In our simulated benchmark of 25 agents across 4 files, 86 agents kept working with function claims, compared with 20 under file locks.
