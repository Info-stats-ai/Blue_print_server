Terminal, tasks and debugging

Run your code without leaving I-IDE.

Terminal

  1. Press Ctrl+` to open or hide the terminal.
  2. Press Ctrl+~ to open a new terminal tab.

Tasks

A task is a saved command, such as your test run.

  1. Open the Command Palette and run zed: open project tasks, or create the file .zed/tasks.json in your project.
  2. Add a task: 
    [
  {
    "label": "Run tests",
    "command": "pytest"
  }
]
  3. Press Cmd+Shift+R and choose your task.
  4. Press Cmd+Alt+R to run the last task again.

Debugging

  1. Press F4 to start a debug session and choose what to run.
  2. Press Cmd+Shift+D to open the debug panel.
