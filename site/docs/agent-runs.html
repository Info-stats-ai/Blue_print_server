Agent runs and sharing

Every task your agent takes on becomes a run. Each run has a goal, steps, an outcome and a review from your team, so the next agents can build on good work and avoid repeating work that was sent back. You decide how much of your agents' work is shared.

The life of a run

  1. Plan. When you give the I-mode agent a task in Agent mode, the task becomes the run's goal.
  2. Run. While the agent works, each step it takes belongs to the run: what it's thinking, what it did and what came back.
  3. Finish. When the agent stops, the run shows how it ended and which files it changed. If you stop the AI yourself, the run shows as stopped.
  4. Review. Teammates mark a finished run Accept or Needs changes. Needs changes asks for a short note on what should change, which is optional and shown on the run. You can't review your own agent's runs.
  5. Remember. Every agent in the session sees reviewed runs. They build on accepted work and avoid repeating work that was sent back.

Reading a run

Runs appear in Team activity under Agent runs, newest first. Each card shows the status, whose agent ran it, the goal, the files it changed and the reviews it has.

IconMeaning
Spinning circleThe run is still going.
Check markThe run finished.
Crossed circleThe run failed, for example because the AI request failed.
SquareSomeone stopped the run.
Thumbs up and a numberHow many teammates accepted it. Point at it to see who.
Thumbs down and a numberHow many teammates asked for changes.

Select steps on a card to see what the agent did, one line per step:

IconStep
ChecklistPlan: the goal.
Thought bubbleReasoning: what the agent was thinking.
HammerAction: a tool it used, such as reading a file or running a command.
Return arrowResult: what came back.
TerminalA terminal run you chose to share.

On your own runs, Waiting for review means your team can see the run and nobody has reviewed it yet. Only you can see this, with a lock, means your sharing was off or paused when it ran.

Steps that don't belong to a run, such as terminal runs and edits from the Agent Panel, appear under Other agent steps.

Choose what you share

Select the people icon in the I-mode panel, then choose under Your agents' work. Your agents always see each other's work on your machine. These settings only control what reaches your team.

LevelWhat your team sees
OffNothing: no runs, no steps, no "working on…" status, and your messages to your own AI stay out of the team chat.
Actions (default)Your messages to your AI, plus the goal, status and changed files of each run and each action.
Actions and reasoningAlso what the agent was thinking.
EverythingAlso the results, and your AI's full answers in the team chat.
  • Pause sharing stops sharing right away, without changing your level. While it's on, your messages to your AI stay out of the team chat too.
  • Private paths… lists files and folders that are never shared, whatever your level is. Steps on those files are left out, and wherever one is named in shared text, such as a run's goal or your message to your AI, it shows as [private]. Secret files such as .env are never shared either.
  • The Auto / Manual switch in Team activity chooses whether files move on their own. See Syncing and merging.
  • Share terminal runs (off by default) shares the command, whether it passed or failed, and the last 25 lines of output when a task finishes.
  • Save shared steps to team memory (off by default) keeps your shared steps and runs, with their reviews, after the session ends. When it's off, they're only shown live and kept in memory for a short while.

Before anything is shared, text that looks like a key or password is masked and long text is shortened.
