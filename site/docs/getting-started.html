Getting started

This guide takes you from a first launch to your first useful work in I. It takes about ten minutes.

I is a code editor with two ways of working. On your own, it's an editor with an AI beside you. With a team, it becomes a shared workspace where people and their agents can see each other's work.

Before you begin

  • I, installed on your Mac. See Installation.
  • A project folder to open.
  • An API key from an AI provider, if you want to use AI. See Set up your AI.

Step 1: Open a project

  1. Start I. The first time, a welcome page lets you choose a theme, base keymap and agent setup. You can change all of these later.
  2. Press Cmd+O and choose your project folder.
  3. Your files appear in the Project Panel on the left. Click a file to open it.
Tip

Coming from another editor? In the welcome page, choose VS Code or Cursor under Import Settings, and pick the matching Base Keymap so your shortcuts keep working.

Step 2: Learn three shortcuts

These three get you almost anywhere in the app.

PressTo
Cmd+Shift+POpen the Command Palette and run any command by name.
Cmd+PFind and open a file by name.
Cmd+Shift+FSearch across the whole project.

Step 3: Get to know the window

Read The I interface for a tour of each part of the window, including the I panel on the right.

Step 4: Set up your AI

Add an API key so the AI in the I panel and the Agent Panel can work. Follow Set up your AI.

Step 5: Ask your AI something

  1. In the I panel, choose Ask at the bottom of the panel.
  2. Type a question about your code, such as "What does this project do?".
  3. Press Return. The answer appears in the panel.

Step 6: Bring in your team

When you're ready to work with others, follow the team session tutorial.
