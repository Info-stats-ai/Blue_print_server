Getting started

This guide takes you from a first launch to your first useful work in I-IDE. It takes about ten minutes.

I-IDE is a code editor with two ways of working. On your own, it's an editor with an AI beside you. With a team, it becomes a shared workspace where people and their agents can see each other's work.

Before you begin

  • I-IDE, installed on your Mac. See Installation.
  • A project folder to open.
  • An API key from an AI provider, if you want to use AI. See Set up your AI.

Step 1: Open a project

  1. Start I-IDE. It opens on its home screen, with two ways to work: Solo (just you and your AI) and I-mode (with your team).
  2. Under Solo, select Open a project and choose your project folder. It opens as a normal code editor with your AI, and nothing is shared. You can switch to I-mode at any time.
  3. Your files appear in the Project Panel on the left. Click a file to open it.
Tip

Coming from another editor? Open the Command Palette (Cmd+Shift+P) and run import vs code settings or import cursor settings. Then set the matching Base Keymap in Settings so your shortcuts keep working.

Step 2: Learn three shortcuts

These three get you almost anywhere in the app.

PressTo
Cmd+Shift+POpen the Command Palette and run any command by name.
Cmd+PFind and open a file by name.
Cmd+Shift+FSearch across the whole project.

Step 3: Get to know the window

Read The I-IDE interface for a tour of each part of the window, including the I-mode panel on the right.

Step 4: Set up your AI

Add an API key so the AI in the I-mode panel and the Agent Panel can work. Follow Set up your AI.

Step 5: Ask your AI something

  1. In the I-mode panel, choose Ask at the bottom of the panel.
  2. Type a question about your code, such as "What does this project do?".
  3. Press Return. The answer appears in the panel.

Step 6: Bring in your team

When you're ready to work with others, follow the team session tutorial.
