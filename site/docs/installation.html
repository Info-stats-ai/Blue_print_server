Installation

I-IDE is in private development. Early testers get the app from us directly; everyone else can join the waitlist.

Get access

  1. Go to the download page.
  2. Enter your work email and select Join the waitlist.
  3. We'll email you when a build is ready for your team.

Install a tester build

If we invited you to test, we sent you a file named like I-1.26.0-arm64.dmg. It runs on Macs with Apple silicon (M1 or later).

  1. Open the .dmg file and drag I into Applications.
  2. Open I from Applications. macOS says it can't check the app for malicious software, because tester builds aren't notarized by Apple yet. Select Done.
  3. Open System Settings > Privacy & Security, scroll down, and select Open Anyway next to the message about I. Confirm with your Mac password.
  4. Sign in with GitHub or Google when I-IDE asks.

You only do this once. To update, replace the app in Applications with the new one we send you.
