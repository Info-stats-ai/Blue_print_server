Installation

I-IDE is in private development. Early testers get the app from us directly; everyone else can join the waitlist.

Get access

  1. Go to the download page.
  2. Enter your work email and select Join the waitlist.
  3. We'll email you when a build is ready for your team.

Install a tester build

If we invited you to test, we sent you a file for your computer. Everyone in a session needs the same version, so install the newest one we send.

macOS

The file is named like I-1.26.0-arm64.dmg. It runs on Macs with Apple silicon (M1 or later), not on older Intel Macs.

  1. Open the .dmg file and drag I into Applications.
  2. Open I from Applications. macOS says it can't check the app for malicious software, because tester builds aren't notarized by Apple yet. Select Done.
  3. Open System Settings > Privacy & Security, scroll down, and select Open Anyway next to the message about I. Confirm with your Mac password.
  4. Sign in with GitHub or Google when I-IDE asks.

You only do this once. To update, replace the app in Applications with the new one we send you.

If there's no Open Anyway button, open Terminal, run xattr -dr com.apple.quarantine /Applications/I.app, then open I again.

Windows

The file is named like I-1.26.0-windows-x64-setup.exe. It runs on 64-bit Windows 10 and 11.

  1. Open the setup file. Windows may say it protected your PC, because tester builds aren't signed yet. Select More info, then Run anyway.
  2. Follow the installer. It installs for your user and doesn't need admin rights.
  3. Open I from the Start menu and sign in with GitHub or Google.

We can also send a .zip instead: unzip it anywhere and open I.exe.

Linux

The file is named like I-1.26.0-linux-x86_64.tar.gz. It runs on 64-bit Intel and AMD computers with Ubuntu 22.04 or newer, or a similar distribution.

  1. Unpack it: tar -xzf I-*-linux-x86_64.tar.gz, then go into the folder it made.
  2. Run ./install.sh. It installs for your user and doesn't need admin rights.
  3. Open I from your apps menu, or run i-ide, and sign in with GitHub or Google.

  • Everyone needs a GitHub or Google account to sign in.
