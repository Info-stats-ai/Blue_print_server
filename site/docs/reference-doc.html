Shared reference

The reference is a REFERENCE.md file that records what your team agreed. Everyone gets it, and agents can follow it.

Write a reference

  1. Select the document button in the tool row.
  2. Your AI asks about what the reference should cover. Answer in the chat.
  3. Select the same button again. Its tooltip now says Click to generate reference now.
  4. Your AI writes the reference from your discussion and code.

You can also type @agent blueprint in team chat to have the service write it with the shared key. Only the owner can do this.

Approve a proposed reference

A reference from someone who isn't the owner arrives as a proposal. The owner selects Approve to publish it or Dismiss to discard it.

Find the reference

It appears as REFERENCE.md in everyone's project and in the Team tab.

Divergences

When a change drifts from the reference, the session counts a divergence in the Team tab.
